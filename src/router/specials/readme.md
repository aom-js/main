# Отсылки

В настоящее время активно используются следующие виды отсылок: `RouteRef` и `ThisRef`, которые не являются по своей сути декораторами, а используются в качестве вспомогательных контейнеров, позволяя в ряде специфических ситуаций получить значение соответствующего элемента.

В общем случае суть их такова, что аргументами тех функций, которые будут вызываться в соответствующем контейнере являются значения, которые в случае `RouteRef` соответствуют endpoint-у, который прямо сейчас выполняется, а в случае `ThisRef` курсору, который может быть в том числе унаследованным элементом.
