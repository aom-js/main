# `@aom-js/schemer`

Пакет описания DTO: компонент-схемы (`@ComponentSchema`), описания свойств (`PropertySchema.*`), mapped-types, рендер JSON Schema, сборщик `$ref`-каскада и собственный формат свёртки схем для кодогенерации (`foldSchemas`).

Документация: https://aom-js.github.io/docs/packages/schemer/

```bash
npm install @aom-js/schemer
```
