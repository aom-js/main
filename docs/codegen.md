# Кодогенерация

> **Черновик автора — исторический документ:** мысли на момент проектирования, а не описание текущего кода. Актуально — [`packages/codegen/readme.md`](../packages/codegen/readme.md); расхождения заметок с кодом — [`architecture.md`](architecture.md#расхождения-с-историческими-заметками).

Важнейшей частью создания распределенного кода является логика код-генерации. При этом она должна уметь работать как для процедур, связанных с изоляторами и схемами, так и, в идеале, с API. Чтобы иметь возможность создавать карты методов, которые можно будет использовать для каких-то стандартных процедур. Но это вторично.

Первично надо решить задачу генерации данных, описанных в schemer и transfer.
